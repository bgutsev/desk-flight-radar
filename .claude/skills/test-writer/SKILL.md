# Test Writer Skill

## Trigger
Use this skill automatically when asked to "write tests", "generate pytest", or "test the backend".

## Instructions
1. Analyze the target Python module.
2. Create a corresponding test file in a `tests/` directory.
3. Strictly use the `pytest` framework.
4. Always include at least one test case using offline mock data.
5. Keep the test simple, functional, and concise.
